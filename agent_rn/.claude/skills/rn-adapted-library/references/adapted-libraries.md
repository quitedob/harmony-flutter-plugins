## 使用说明

### 安装已适配库

```bash
# 使用 npm 安装鸿蒙化版本
npm install @react-native-oh-tpl/<package_name>

# 或使用 yarn
yarn add @react-native-oh-tpl/<package_name>
```

### Autolinking 配置

大部分已适配库支持 Autolinking，安装后会自动链接。如需手动配置，请参考各库的使用文档。

### 纯 JS 库使用

纯 JS 库无需安装鸿蒙化版本，直接使用原库即可：

```bash
npm install <original_package_name>
```
