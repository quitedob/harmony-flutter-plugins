

```
1. typedef struct OH_ArkUI_BackgroundColorStyle OH_ArkUI_BackgroundColorStyle
```

## 概述

PhonePC/2in1TabletTVWearable

定义背景颜色样式。

可以通过[OH\_ArkUI\_BackgroundColorStyle\_Create](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-styled-string-h#oh_arkui_backgroundcolorstyle_create)接口创建对应的背景颜色样式对象。

可以通过[OH\_ArkUI\_BackgroundColorStyle\_Destroy](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-styled-string-h#oh_arkui_backgroundcolorstyle_destroy)接口销毁背景颜色样式对象。

对象创建后通过[OH\_ArkUI\_BackgroundColorStyle\_SetColor](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-styled-string-h#oh_arkui_backgroundcolorstyle_setcolor)和[OH\_ArkUI\_BackgroundColorStyle\_SetRadius](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-styled-string-h#oh_arkui_backgroundcolorstyle_setradius)接口设置背景颜色和圆角。

**起始版本：** 24

**所在头文件：** [styled\_string.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-styled-string-h)
