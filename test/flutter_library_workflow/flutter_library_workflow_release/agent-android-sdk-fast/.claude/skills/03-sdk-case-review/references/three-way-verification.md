# 程序化验证指南

## 概述

本指南提供 SDK 测试用例评审阶段的程序化验证代码索引。

**适用范围**：SDK 测试用例评审

---

## 验证脚本

### 两方数据一致性验证

**验证内容**：
1. 模块数校验：测试点 JSON = 测试用例 JSON
2. 用例总数校验：两方一致
3. 级别分布校验：L0/L1/L2 各级别数量一致
4. 模块级用例数校验：每个模块的用例数一致

**验证方法**：
- 读取 `01-test-points.json`，提取模块列表和测试点信息
- 读取 `04-test-cases.json`，提取模块列表和用例信息
- 对比两方数据，输出一致性报告

**校验失败处理**：
- 任何一项校验失败，评审直接判定为**不通过**
- 在评审报告中明确列出不一致的详情
- 要求重新生成上一阶段的产物
