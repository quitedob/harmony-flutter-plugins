# SDK 类型识别详解

## 概述

本文档提供 SDK 类型识别的详细信息，包括特征关键词、典型示例和测试策略映射。

---

## SDK 类型分类详解

### 1. 平台交互类（platform_interaction）

**特征关键词**：
- 蓝牙、相机、位置、传感器、屏幕、常亮
- 系统调用、NAPI、回调机制
- 电话、通讯录、短信、通知、定位

**典型示例**：
- 蓝牙状态监听 SDK
- 相机调用 SDK
- 位置服务 SDK
- 屏幕常亮 SDK

**测试重点**：
- 系统行为模拟
- 权限处理
- 回调机制
- 平台兼容性

### 2. 业务功能类（business_feature）

**特征关键词**：
- 支付、地图、推送、OCR、分享
- 登录、认证、数据统计
- 第三方 SDK 集成

**典型示例**：
- 支付宝/微信支付 SDK
- 地图 SDK
- 推送服务 SDK

**测试重点**：
- 业务流程正确性
- 错误处理
- 数据安全
- 数据一致性

### 3. 数据处理类（data_processing）

**特征关键词**：
- 数据处理、计算、编解码
- 加密、解密、压缩
- 格式转换、序列化

**典型示例**：
- JSON 解析 SDK
- 加密解密 SDK
- 图像编解码 SDK

**测试重点**：
- 输入边界值
- 输出正确性
- 性能验证
- 对比验证

### 4. UI 组件类（ui_component）

**特征关键词**：
- 组件、UI、渲染、Widget
- 布局、动画、样式
- 弹窗、Toast、Dialog

**典型示例**：
- Toast 显示 SDK
- 自定义弹窗 SDK
- 图表库 SDK

**测试重点**：
- UI 渲染正确性
- 交互体验
- 动画效果
- 状态管理

### 5. 原生库类（native_library）

**特征关键词**：
- JNI/NAPI、原生库、.so、动态库
- C/C++ 绑定、底层调用
- 桥接、内存管理

**典型示例**：
- 音视频处理库
- 加密解密库
- 图像处理库

**测试重点**：
- 桥接正确性
- 内存安全
- 线程安全
- 稳定性测试

## 类型识别规则

### 识别流程

1. **提取功能描述**：从 PRD 中提取 SDK 功能描述
2. **关键词匹配**：匹配各类型的特征关键词
3. **API 分析**：分析 API 签名和参数特征
4. **综合判定**：根据匹配结果综合判定类型

### 优先级规则

当多个类型都有匹配时，按以下优先级判定：

1. 原生库类（特征最明显）
2. 平台交互类（涉及系统 API）
3. 业务功能类（第三方 SDK）
4. UI 组件类（有 UI 渲染）
5. 数据处理类（兜底）
