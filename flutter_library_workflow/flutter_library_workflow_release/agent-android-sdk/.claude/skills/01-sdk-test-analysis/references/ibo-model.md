# IBO 模型详解

## 概述

IBO（Input-Behavior-Output）模型是测试分析的核心方法论，用于对每个功能模块进行结构化测试分析。

## 模型定义

| 维度 | 含义 | 分析内容 | 测试方法 |
|------|------|----------|----------|
| Input | 输入 | 输入参数的类型和特征 | 等价类划分、边界值分析、空值测试 |
| Behavior | 行为 | 功能行为的特征 | 状态迁移测试、判定表、并发测试 |
| Output | 输出 | 输出数据的类型和特征 | 空集合测试、边界值分析、格式验证 |

## 分析流程

1. **识别输入特征** → 选择输入测试方法
2. **识别行为特征** → 选择行为测试方法
3. **识别输出特征** → 选择输出测试方法
4. **生成测试点** → 标注级别（L0/L1/L2）

## 输入特征分类

| 特征类型 | 说明 | 示例 | 适用测试方法 |
|----------|------|------|-------------|
| 必填参数 | 不可为空的输入 | 用户ID、配置项 | 空值测试、边界值 |
| 可选参数 | 可以省略的输入 | 超时时间、默认值 | 等价类划分（有/无） |
| 枚举参数 | 有限取值集合 | 状态类型、操作类型 | 等价类划分（每个枚举值） |
| 数值参数 | 连续/离散数值 | 大小、数量、索引 | 边界值分析 |
| 对象参数 | 复合数据结构 | 配置对象、请求体 | 等价类划分（字段组合） |
| 集合参数 | 列表/数组 | 数据列表、ID 列表 | 边界值（空、1、多）、顺序 |

## 行为特征分类

| 特征类型 | 说明 | 适用测试方法 |
|----------|------|-------------|
| 状态转换 | 有明确状态机 | 状态迁移测试 |
| 条件组合 | 多条件判定 | 判定表/因果图 |
| 顺序依赖 | 操作顺序影响结果 | 场景测试 |
| 并发行为 | 多线程/异步操作 | 并发测试、竞态测试 |
| 副作用 | 操作有持久影响 | 副作用验证 |
| 幂等性 | 重复调用结果一致 | 幂等性测试 |

## 输出特征分类

| 特征类型 | 说明 | 适用测试方法 |
|----------|------|-------------|
| 返回值 | 方法返回数据 | 返回值验证 |
| 回调通知 | 异步结果通知 | 回调验证 |
| 状态变化 | 数据/状态更新 | 前后对比验证 |
| 副作用 | 间接影响 | 副作用验证 |

## 测试点生成原则

1. 每个 IBO 维度至少生成 1 个测试点
2. P0 模块：正常流程全部覆盖，异常/边界最多各 2 个
3. P1 模块：正常流程全部覆盖，异常/边界最多各 1 个
4. P2 模块：只覆盖正常流程
