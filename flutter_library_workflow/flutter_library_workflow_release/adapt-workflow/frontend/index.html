添加插件仓库

输入插件的 Git 仓库地址，支持 Monorepo 子包地址（自动识别 /tree/ 路径），添加后可在列表中进行克隆

留空表示仓库根目录即插件根目录；填写相对路径，不含前后斜杠

从 Pub.dev 批量下载

格式说明

  • 包名 — 使用最新版本，如 dio
  • 包名:版本号 — 指定版本，如 dio:5.4.0
  • 包1, 包2, 包3 — 联合插件，第一个包名作为主目录

版本号格式

支持标准 semver 格式：1.0.0、1.0.0-dev、1.0.0-beta.1

上传 ZIP 包导入 SDK

名称必须以字母开头，只能包含字母、数字、下划线和连字符（1-64字符）

ZIP 包内应包含 Android SDK 源码（Maven 或 Gradle 项目）

支持的项目结构

  • pom.xml — Maven 项目（根目录或子目录）
  • build.gradle — Gradle 项目（根目录或子目录）
  • settings.gradle — Gradle 多模块项目

注意事项

  • 最大文件大小：100MB
  • 系统会自动识别 ZIP 内的项目结构（最多递归3层）
  • 仅支持 Android SDK Profile

批量添加 Git 仓库

格式说明

  • https://... — 标准 Git HTTPS 地址
  • https://.../tree/branch/path — Monorepo 子包地址，自动拆分为仓库地址 + 子包路径
  • 每行一个地址，空行和 # 开头的行会被忽略
  • 添加后自动触发批量克隆，无需手动操作
