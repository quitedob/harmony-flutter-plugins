# IBO 模型详解

## 概述

IBO（Input-Behavior-Output）模型是一种结构化测试分析方法，通过输入、行为、输出三个维度进行全面的测试分析。

---

## IBO 模型核心表格

### Input（输入）类型与测试方法

| 输入类型 | 识别关键词 | 测试方法 | 测试点示例 |
|----------|------------|----------|-----------|
| String | String、路径、名称、消息 | 等价类划分、边界值分析 | 有效文本、空字符串、超长文本 |
| 数值 | int、double、Duration | 边界值分析 | 0、最小值、最大值、负数 |
| 可空 | null、Optional、? | 空值测试 | 传 null、不传值 |
| 对象 | Object、Widget、Event | 对象构造测试 | 完整对象、部分属性、空对象 |
| 枚举 | Toast、Gravity、Color | 枚举值遍历 | 所有枚举值逐一验证 |
| 布尔 | bool、开关 | 状态切换测试 | true/false、开启/关闭 |
| 列表 | List、Array | 空集合测试 | 空列表、单元素、多元素 |

### Behavior（行为）类型与测试方法

| 行为类型 | 识别关键词 | 测试方法 | 验证内容 |
|----------|------------|----------|---------|
| 状态转换 | 状态、Stream | 状态迁移测试 | 状态变化正确、不遗漏 |
| 数据计算 | 计算、统计 | 因果图与判定表 | 计算结果准确 |
| 异步行为 | Future、回调 | 异步行为测试 | 异步执行正确 |
| 队列管理 | 队列、FIFO | 队列调度测试 | 按序处理、不丢失 |
| 并发处理 | 并发、多线程 | 并发测试 | 不冲突、数据一致 |
| UI 渲染 | Widget、Overlay | UI 测试 | 布局正确、动画流畅 |

### Output（输出）类型与测试方法

| 输出类型 | 识别关键词 | 测试方法 | 验证内容 |
|----------|------------|----------|---------|
| 列表 | List、Array | 空集合测试 | 空列表、元素完整性 |
| 数值 | int、double | 边界值分析 | 精度、范围 |
| 对象 | Object、Result | 属性访问测试 | 属性完整、非空 |
| 可空 | null、Optional | 空值处理测试 | null 处理正确 |
| 布尔 | bool | 真值表验证 | true/false 场景完整 |
| 字符串 | String | 格式验证 | 格式正确、内容完整 |

## 测试点生成规则

### 从 Input 生成测试点

| 输入特征 | 生成规则 | 示例 |
|----------|----------|------|
| String 输入 | 有效值、空值、超长值 | 能正常显示有效消息、能正确处理空消息 |
| 数值输入 | 边界值（0、最小、最大） | 能正确处理 0 值、能处理最大值 |
| 枚举输入 | 遍历所有枚举值 | 能显示 SHORT 时长、能显示 LONG 时长 |
| 可空输入 | 传值、传 null | 能处理传值场景、能处理 null 场景 |
| 布尔输入 | true、false | 能开启功能、能关闭功能 |

### 从 Behavior 生成测试点

| 行为特征 | 生成规则 | 示例 |
|----------|----------|------|
| 状态转换 | 覆盖所有状态迁移 | 能从状态 A 切换到状态 B |
| 数据计算 | 验证计算结果 | 计算结果准确 |
| 异步行为 | 验证异步执行 | 异步操作正确完成 |
| 队列管理 | 验证 FIFO 顺序 | 多个请求按序处理 |
| UI 渲染 | 验证显示效果 | UI 显示符合预期 |

### 从 Output 生成测试点

| 输出特征 | 生成规则 | 示例 |
|----------|----------|------|
| 列表输出 | 空列表、有元素 | 无数据时返回空列表、有数据时返回完整列表 |
| 数值输出 | 精度验证 | 返回值精度正确 |
| 对象输出 | 属性完整性 | 返回对象包含所有必要属性 |
| 可空输出 | null 处理 | 无数据时返回 null |

## 应用示例：Toast 显示功能

### Input 分析

| 输入参数 | 类型 | 识别的测试方法 | 生成的测试点 |
|----------|------|---------------|-------------|
| 消息内容 | String | 等价类划分、边界值分析 | 输入有效消息、空消息、超长消息 |
| 显示时长 | 枚举（SHORT/LONG） | 枚举值遍历 | 显示 SHORT 时长、显示 LONG 时长 |
| 显示位置 | 枚举（TOP/CENTER/BOTTOM） | 枚举值遍历 | 显示在顶部、居中显示、显示在底部 |
| 背景色 | Color | 有效值验证 | 使用默认背景色、使用自定义背景色 |

### Behavior 分析

| 行为特征 | 识别的测试方法 | 生成的测试点 |
|----------|---------------|-------------|
| 消息显示 | UI 测试 | Toast 正确显示在界面上 |
| 自动消失 | 异步行为测试 | Toast 在指定时长后自动消失 |
| 平台检测 | 系统交互测试 | 在不同平台上正确检测并显示 |

### Output 分析

| 输出 | 类型 | 识别的测试方法 | 生成的测试点 |
|------|------|---------------|-------------|
| 操作结果 | bool | 真值表验证 | 成功时返回 true、失败时返回 false |
| Toast 显示 | UI | 视觉验证 | Toast 显示内容正确、布局正确 |

### 基于 IBO 生成的测试点汇总

| 维度 | 测试点 |
|------|--------|
| Input | 输入有效消息、空消息、超长消息 |
| Input | 显示时长为 SHORT、LONG |
| Input | 显示位置为 TOP、CENTER、BOTTOM |
| Behavior | Toast 正确显示、按时长消失 |
| Output | 返回 true 表示成功 |
