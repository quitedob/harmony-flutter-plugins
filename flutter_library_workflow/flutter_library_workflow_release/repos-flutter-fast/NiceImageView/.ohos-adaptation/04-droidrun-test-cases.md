| 属性 | 说明 |
|------|------|
| 级别 | L0 |
| 前置条件 | Demo 应用（com.example.example_auto）已安装并成功启动，首页模块索引列表可见 |

**步骤：**
1. 确认首页显示【NiceImageView 功能模块】标题与八个功能模块索引列表

**预期结果**：一键测试全部执行完成，全部用例判定为符合预期（PASS），无失败用例，NiceImageView 组件在各参数组合下均正常构建与渲染。
