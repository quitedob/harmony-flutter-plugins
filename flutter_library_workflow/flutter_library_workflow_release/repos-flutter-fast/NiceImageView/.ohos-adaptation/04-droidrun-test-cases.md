# NiceImageView DroidRun 测试用例

## DR-01: 圆形模式冒烟测试

| 属性 | 说明 |
|------|------|
| 级别 | L0 |
| 前置条件 | Demo 应用已启动并显示 NiceImageView 组件 |

**步骤：**
1. 确认页面显示 **【圆形模式开关】**
2. 点击 **【圆形模式开关】** 切换为开启
3. 检查页面无崩溃或错误提示

**预期结果**：圆形模式切换后组件正常渲染为圆形，无崩溃

(API: isCircle)

---

## DR-02: 边框显示冒烟测试

| 属性 | 说明 |
|------|------|
| 级别 | L0 |
| 前置条件 | 圆形模式开启 |

**步骤：**
1. 向右拖动 **【边框宽度滑块】** 到非零值
2. 观察 NiceImageView 组件

**预期结果**：边框正确显示在图片周围

(API: borderWidth, borderColor)
