# 测试点生成与验证点编写指南

## 概述

本文档说明如何基于 IBO 分析生成测试点，以及如何编写符合规范的测试点和验证点。

---

## 测试点生成规则

### 从 Input 生成测试点

| 输入特征 | 生成规则 | 示例 |
|----------|----------|------|
| String 输入 | 有效值、空值、超长值 | 能正常显示有效消息、能正确处理空消息 |
| 数值输入 | 边界值（0、最小、最大） | 能正确处理 0 值、能处理最大值 |
| 枚举输入 | 遍历所有枚举值 | 能显示 SHORT 时长、能显示 LONG 时长 |
| 可空输入 | 传值、传 null | 能处理传值场景、能处理 null 场景 |
| 布尔输入 | true、false | 能开启功能、能关闭功能 |

### 从 Behavior 生成测试点

| 行为特征 | 生成规则 | 示例 |
|----------|----------|------|
| 状态转换 | 覆盖所有状态迁移 | 能从状态 A 切换到状态 B |
| 数据计算 | 验证计算结果 | 计算结果准确 |
| 异步行为 | 验证异步执行 | 异步操作正确完成 |
| 队列管理 | 验证 FIFO 顺序 | 多个请求按序处理 |
| UI 渲染 | 验证显示效果 | UI 显示符合预期 |

### 从 Output 生成测试点

| 输出特征 | 生成规则 | 示例 |
|----------|----------|------|
| 列表输出 | 空列表、有元素 | 无数据时返回空列表、有数据时返回完整列表 |
| 数值输出 | 精度验证 | 返回值精度正确 |
| 对象输出 | 属性完整性 | 返回对象包含所有必要属性 |
| 可空输出 | null 处理 | 无数据时返回 null |

## 测试点级别划分

### 级别判定规则

| 模块优先级 | 测试类型 | 级别 |
|-----------|---------|------|
| P0 | 正常流程 | L0 |
| P0 | 异常/边界 | L1 |
| P1 | 正常流程 | L1 |
| P1 | 异常/边界 | L2 |
| P2 | 正常流程 | L2 |
| P2 | 异常/边界 | L3 |

### 级别分布参考

| 级别 | 占比参考 | 说明 |
|------|----------|------|
| L0 | 25-35% | 核心功能的正常流程 |
| L1 | 40-50% | 核心功能异常/边界 + P1 正常流程 |
| L2 | 15-25% | P1 异常/边界 + P2 正常流程 |
| L3 | 0-5% | P2 异常/边界 |

## 验证点编写要求

### 核心要求

- **必须具体明确**：体现测试点的具体验证内容
- **禁止模糊描述**：不能使用"功能执行正确，结果符合预期"等通用描述
- **必须有判定标准**：测试人员可以根据验证点明确判定 pass/fail

### 示例对比

| 测试点 | 验证点（正确）✅ | 验证点（错误）❌ |
|--------|--------------|--------------|
| 能正常显示短时长 Toast | Toast 显示时长为短时长（约 2 秒） | 功能执行正确，结果符合预期 |
| 能显示将来电号码 | 显示正确的 11 位手机号码 | 返回数据准确 |
| 能统计通话时长 | 显示通话持续时间（秒），随时间递增 | 统计结果正确 |
| 能处理空消息输入 | Toast 不显示或使用默认消息 | 功能正常处理 |

## 测试点描述规范

### API 层面 → 功能层面转化

| API 层面描述（避免）❌ | 功能层面描述（推荐）✅ |
|---------------------|---------------------|
| `调用 showToast() 方法成功` | `能正常显示 Toast` |
| `访问 status 属性返回 CALL_INCOMING` | `能显示状态为"来电中"` |
| `调用 stream 订阅事件流` | `能接收事件流更新` |
| `调用 enable() 方法成功` | `能开启功能` |
| `调用 disable() 方法成功` | `能关闭功能` |

### 转化规则总结

| API 层面词汇 | 功能层面转化 |
|------------|-------------|
| `调用 XXX()` | `能执行 XXX` / `能正常 XXX` |
| `访问 XXX 属性` | `能获取/显示 XXX` |
| `返回 XXX 值` | `能正确显示 XXX` |
| `订阅 XXX 事件` | `能接收 XXX 事件` |

## 测试点格式规范

| 字段 | 要求 | 示例 |
|------|------|------|
| 测试点编号 | 模块 ID+ 序号 | F-01-01 |
| 功能模块 | 模块名称 | 原生 Toast 显示 |
| 测试点 | 具体测试内容描述（功能视角） | 能正常显示默认 Toast，约 2 秒后自动消失 |
| 验证点 | 具体的验证标准 | Toast 显示默认消息，约 2 秒后自动消失 |
| 覆盖 API | 被测 API 名称 | showToast |
| 测试点级别 | L0/L1/L2/L3 | L0 |
