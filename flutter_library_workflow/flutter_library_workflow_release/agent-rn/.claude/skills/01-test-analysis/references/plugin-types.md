# 插件类型识别详解

## 概述

本文档提供插件类型识别的详细信息，包括特征关键词、典型示例和测试策略映射。

---

## 插件类型分类详解

### 1. 平台交互类（platform_interaction）

**特征关键词**：
- 相机、蓝牙、存储、传感器、屏幕、常亮
- 原生 API、系统调用、MethodChannel、EventChannel
- 电话、通讯录、短信、通知、定位

**典型示例**：
- phone_state（电话状态监听）
- camera（相机调用）
- blue_state（蓝牙状态）
- wake_lock（屏幕常亮）

**测试重点**：
- 系统 API 调用正确性
- 权限处理
- 平台兼容性

### 2. 业务功能类（business_feature）

**特征关键词**：
- 支付、地图、推送、OCR、分享
- 登录、认证、数据统计
- 第三方 SDK 集成

**典型示例**：
- 支付宝/微信支付 SDK
- 腾讯地图/高德地图
- 推送服务 SDK

**测试重点**：
- 业务流程正确性
- 错误处理
- 数据安全

### 3. UI 组件类（ui_component）

**特征关键词**：
- 组件、UI、渲染、Widget
- 布局、动画、样式
- 弹窗、Toast、Dialog

**典型示例**：
- fluttertoast（Toast 显示）
- 自定义弹窗组件
- 图表库

**测试重点**：
- UI 渲染正确性
- 交互体验
- 动画效果

### 4. 架构与工具类（architecture_tool）

**特征关键词**：
- 工具、封装、通用、辅助
- 路由、状态管理、网络请求
- 数据转换、格式化

**典型示例**：
- dio（网络请求）
- provider（状态管理）
- json_serializable（数据序列化）

**测试重点**：
- 功能正确性
- 性能表现
- 接口兼容性

### 5. FFI 类（ffi）

**特征关键词**：
- FFI、原生库、.so、动态库
- C/C++ 绑定、底层调用

**典型示例**：
- 音视频处理库
- 加密解密库

**测试重点**：
- 原生库加载
- 内存安全
- 接口调用正确性

## 类型识别规则

### 识别流程

1. **提取功能描述**：从 PRD 中提取插件功能描述
2. **关键词匹配**：匹配各类型的特征关键词
3. **API 分析**：分析 API 签名和参数特征
4. **综合判定**：根据匹配结果综合判定类型

### 优先级规则

当多个类型都有匹配时，按以下优先级判定：

1. FFI 类（特征最明显）
2. 平台交互类（涉及系统 API）
3. 业务功能类（第三方 SDK）
4. UI 组件类（有 UI 渲染）
5. 架构与工具类（兜底）

| ffi | 重点覆盖 | 重点覆盖 | 稳定性/内存 | 内存安全 |
