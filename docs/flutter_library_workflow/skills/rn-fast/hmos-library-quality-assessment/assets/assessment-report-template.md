### 单条发现书写规范（填表说明）

- **一条发现 = 表格一行**，列固定为：`级别 ｜ 发现 ｜ 位置 file:line ｜ 说明 ｜ 修复建议`，列顺序与表头不要改。
- **级别**只用 🔴`[blocking]` / 🟡`[important]` / 🟢`[nit]` / 💡`[suggestion]`，勿自创同义词。
- **位置**精确到 `file:line`（如 `src/main/ets/api/HttpClient.ets:42`）；💡 启发式线索无确切定位时填 `—`。
- **说明**写问题与影响并引用具体判据；**修复建议**写可操作改法，必要时在单元格内用 `❌前 / ✅后` 简述。
- 单元格内若需出现 `|`，用 `\|` 转义，避免破坏表格列。
- 某子维度无发现时，保留小标题并在表格下写一行 `无发现`，不要删表头。
